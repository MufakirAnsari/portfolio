## 1. Distributional Discriminative Feature Filtering: A Scalable Framework for High-Dimensional Low-Sample-Size Biomedical Data
* **Paper Title:** Distributional Discriminative Feature Filtering: A Scalable Framework for High-Dimensional Low-Sample-Size Biomedical Data
* **Authors:** Mufakir Ansari, Lauren Popp, Tomojit Ghosh
* **Focus Area:** Bioinformatics, Feature Selection, High-Dimensional Low-Sample-Size (HDLSS) Data, Biomarker Discovery
* **Publication / Identifier:** 2026 25th IEEE International Conference on Machine Learning and Applications (ICMLA), DOI: 10.1109/ICMLA69890.2026.00030

### Key Portfolio Highlights (7 Points):
1. **Distribution-Aware Feature Selection Framework:** Developed DDFF, a novel filter-based feature selection algorithm specifically designed for High-Dimensional Low-Sample-Size (HDLSS) biological datasets ($p \gg n$), which scores and ranks candidate biomarkers by evaluating discrepancies between class-conditional empirical Probability Mass Functions (PMFs).
2. **Optimal Linear Time Complexity $O(pn)$:** Proved that DDFF operates in strictly linear time $O(pn)$ with zero pairwise feature interaction overhead, matching the scalability of simple univariate statistical filters while enabling seamless parallelization across tens of thousands of genomic variables.
3. **Information-Theoretic Total Variation Distance Equivalence:** Derived a direct mathematical proof establishing that the proposed $DDFF_{\ell_1}$ discrepancy measure is exactly equivalent to twice the discrete Total Variation (TV) distance between class distributions ($S_j^{(\ell_1)} = 2 \cdot TV(P_j, Q_j)$), providing rigorous probabilistic foundations for feature discriminability.
4. **Detecting Higher-Order Variance and Multimodal Structure:** Demonstrated through synthetic experiments that DDFF captures discriminative signals completely invisible to classical filters: when class distributions shared identical means ($\mu_1 = \mu_2 = 0$) but differing variances ($\sigma_1^2 = 1, \sigma_2^2 = 5$) or bimodal structures, Fisher Score collapsed to near-zero (0.0006 and 0.0011), whereas $DDFF_{\ell_1}$ robustly identified separation with scores of **0.696** and **1.464** ($>3\times$ higher than Mutual Information’s 0.4507).
5. **Cross-Modality Biomedical Benchmark Validation:** Evaluated DDFF across six diverse benchmarks spanning synthetic challenges (Madelon), cancer microarrays (Prostate GE, ALL/AML leukemia, Colon adenocarcinoma), mass spectrometry (Arcene with 10,000 features), and clinical RNA-seq (Crohn's disease with 23,813 genes post-imputation).
6. **Superior Classification Accuracy with Compact Feature Subsets:** Across 25 stratified random trials, $DDFF_{\ell_1}$ achieved **85.3% peak 5-NN accuracy on Madelon** (outperforming Mutual Information’s 61.4% by +23.9%) and **94.3% accuracy on Prostate GE**. On non-linear shallow Artificial Neural Networks (ANN), DDFF maintained top performance (86.0% on Madelon and 93.7% on Prostate GE), verifying that selected feature subsets preserve non-linear discriminative structure across classifier families.
7. **Empirical Invariance to Histogram Resolution:** Conducted a comprehensive bin-size ablation study across $B \in \{5, 10, 15, 20, 25\}$, showing that classification accuracy varied by less than 3 percentage points across all datasets (Colon cancer maintained an exact 83.7% accuracy across all bin counts), establishing $B = 10$ as a universally robust default.

## 2. From Text to Returns: Using Large Language Models for Mutual Fund Portfolio Optimization and Risk-Adjusted Allocation
* **Paper Title:** From Text to Returns: Using Large Language Models for Mutual Fund Portfolio Optimization and Risk-Adjusted Allocation
* **Authors:** Mufakir Qamar Ansari*, Abrar Hossain*,  Haziq Jeelani, Monia Digra, Fayeq Jeelani Syed (*equal contribution)
* **Focus Area:** Generative AI in Finance, Large Language Models (LLMs), RAG, Blended Portfolio Optimization
* **Publication / Identifier:** arXiv:2512.05907v1 [cs.CE], December 2025

### Key Portfolio Highlights:
1. **Generative AI Financial Framework with RAG:** Designed and implemented an end-to-end financial decision-support pipeline combining open-source Large Language Models (LLMs) with Retrieval-Augmented Generation (RAG) to dynamically optimize sector-level mutual fund asset allocations based on multimodal structured financial data and macroeconomic indicators (interest rates, inflation).
2. **Vector Database Retrieval Architecture:** Embedded structured mutual fund metrics (NAV, historical percentage returns, volatility, and sector exposures across Tech, Healthcare, Finance, and Energy) using the `all-MiniLM-L6-v2` embedding model stored in a Chroma vector database, retrieving top-$k$ relevant contextual documents to ground LLM reasoning.
3. **Comparative Evaluation of Open-Source LLMs:** Conducted a systematic benchmark comparing Microsoft Phi-2 (2.7B), Mistral 7B, and Zephyr 7B Beta on sectoral portfolio rebalancing across three distinct mutual funds (Fund A, Fund B, Fund C).
4. **Superiority of Financial Fine-Tuning (Zephyr 7B):** Demonstrated that domain-fine-tuned Zephyr 7B consistently outperformed base Mistral 7B and lightweight Phi-2 across all evaluated metrics, achieving the highest absolute returns and risk-adjusted returns (RAR), demonstrating superior capability to synthesize non-linear macroeconomic dependencies.
5. **Continuous Blended Optimization Strategy:** Developed a novel blended optimization technique that incrementally adjusts portfolio exposure ratios ($\lambda \in [0.0, 1.0]$) between aggressive LLM recommendations and classical risk-minimizing allocations, successfully balancing the trade-off between return maximization and downside volatility.
6. **Peak Risk-Adjusted Returns (Sharpe Ratio 1.5751):** Across all allocation strategies, Zephyr 7B achieved a peak Sharpe ratio of **1.5751** (at exposure ratio 0.0) with an annualized return of 0.2314 and volatility of 0.1328, maintaining favorable Sharpe ratios ($>1.37$) and achieving up to **2.41% risk reduction** across conservative blended portfolios.
7. **Resource-Constrained CPU Deployment Feasibility:** Engineered a CPU-compatible pipeline for Microsoft Phi-2 using `low_cpu_mem_usage=True` within the HuggingFace Transformers pipeline, proving the feasibility of deploying generative financial reasoning on edge workstations without dedicated GPU infrastructure.

## 4. Disentangling Architecture, Strategy, and Adaptation in Day-Ahead Electricity Price Forecasting
* **Paper Title:** Disentangling Architecture, Strategy, and Adaptation in Day-Ahead Electricity Price Forecasting: A Multi-Model Benchmark on Volatile US Markets
* **Authors:** Mufakir Qamar Ansari, Mudabir Qamar Ansari
* **Focus Area:** Energy Economics, Time Series Deep Learning, Conformal Prediction, Wholesale Electricity Markets
* **Institutional Affiliation:** Wright State University & Lamar University
* **Publication Status:** Submitted to *Computational Economics (Springer Nature)*; Code: https://github.com/MufakirAnsari/Energy-Cost-Prediction

### Key Portfolio Highlights:
1. **Unprecedented Multi-Model Post-2020 US Market Benchmark:** Conducted the most comprehensive empirical benchmark to date on post-2020 US wholesale power markets, analyzing 21 forecasting configurations across 17 model families on PJM (capacity market) and ERCOT (energy-only market) over 2019–2025 (~61,000 hours per market) across 4 extreme volatility regimes including Winter Storm Uri ($>\$9,000$/MWh spikes) and the European gas crisis spillover.
2. **SOTA Deep Learning Outperformance Over Gradient Boosting:** Established that direct multi-output Bidirectional LSTM (BiLSTM) achieves new state-of-the-art accuracy, delivering test-set MAE of **\$4.57/MWh on PJM** and **\$3.64/MWh on ERCOT**, decisively outperforming static tree models (LightGBM MAE \$7.71 and \$8.55) and rolling tree models (LightGBM MAE \$6.69 and \$7.59), statistically validated via Diebold-Mariano tests with Benjamini-Hochberg FDR control at $p < 0.01$.
3. **Disproving Tree Dominance via Leak-Free Operational Protocols:** Proved that traditional tree superiority in EPF is an artifact of short-term autoregressive causal leakage ($<24$h lags). By strictly enforcing a 24-hour minimum lag to emulate true noon day-ahead clearing, recursive 1-step tree models suffered compounding errors, whereas deep direct multi-output architectures predicted all 24 hours simultaneously in a single forward pass. A controlled lag ablation showed adding 1–12h lags artificially dropped tree MAE by **47% on PJM and 62% on ERCOT** ($p < 10^{-100}$).
4. **Empirical Diagnosis of Conformal Prediction Failure under Regime Shift:** Discovered and proved that Conformalized Quantile Regression (CQR) fails to maintain its 90% finite-sample coverage guarantee under market regime shift, diverging wildly to 95.4% over-coverage on PJM and 80.1% under-coverage on ERCOT. Formal two-sample Kolmogorov-Smirnov ($p < 10^{-100}$) and Anderson-Darling tests proved severe violation of the exchangeability assumption between 2022 calibration and 2024–2025 test periods. In contrast, non-parametric Quantile Regression Forests (QRF) hit target coverage robustly (87.0% on PJM, 90.2% on ERCOT).
5. **Decisive Compute-Accuracy Pareto Dominance:** Demonstrated that a single 20-minute static training run of BiLSTM achieved **32% lower error** than the best rolling LightGBM model requiring 24 monthly retraining cycles. While rolling BiLSTM improved further to \$3.66/MWh (PJM), its 192 GPU-hour computational cost establishes that static BiLSTM provides the optimal accuracy-per-compute-hour trade-off for industrial deployment.
6. **Counter-Intuitive Cross-Market Zero-Shot Generalization:** Discovered that zero-shot transfer of tree models trained exclusively on a stable capacity market (PJM) to an energy-only market (ERCOT) actually yielded lower error than training directly on ERCOT data (LightGBM MAE improved from \$8.55 to \$8.14/MWh; XGBoost improved from \$8.42 to \$7.77/MWh; QRF achieved \$7.51/MWh). Stable training forces trees to learn fundamental load and weather drivers rather than greedily overfitting to erratic, non-repeating spike magnitudes.
7. **Revealing the Economic-Statistical Disconnect:** Simulated day-ahead virtual bidding with ISO clearing fees (\$0.50/MWh) and $0.3\sigma$ trailing slippage. Revealed that superior point accuracy (MAE) does not guarantee highest financial profit: rolling LightGBM captured the highest total PnL (\$19,758 on PJM, Sharpe 14.67) by capturing large directional swings, while BiLSTM achieved a higher win rate (95.2% vs 93.7%) on low-margin days. Applying risk-aware CQR and Bayesian MC Dropout filters scaled position sizes dynamically, boosting the Sharpe ratio up to **22.69**.
8. **Evaluation of Time-Series Foundation Models (TSFMs):** Conducted the first evaluation of Amazon's Chronos-Bolt v1 and v2 on US electricity prices; showed that zero-shot foundation models trail domain-trained deep learning (MAE 6.85–7.02 on PJM) and that post-hoc linear residual injection (Ridge-residuals) severely degraded accuracy on volatile grids (ERCOT MAE exploded to \$11.84/MWh), exposing the danger of two-stage linear covariate adaptation under regime shift.

## 5. DynaCut: Bounding Classical Memory in Quantum Circuit Knitting via Resource-Aware Tensor Network Reconstruction
* **Paper Title:** DynaCut: Bounding Classical Memory in Quantum Circuit Knitting via Resource-Aware Tensor Network Reconstruction
* **Authors:** Mufakir Qamar Ansari, Mudabir Qamar Ansari
* **Focus Area:** Quantum Circuit Knitting, Quasiprobability Decomposition (QPD), Tensor Networks, Hybrid Quantum-HPC Compilation, Heavy-Hex Topology
* **Publication Status:** Submitted to *Quantum Machine Intelligence (Springer Nature)*; Code: https://github.com/MufakirAnsari/DynaCut

### Key Portfolio Highlights:
1. **Resource-Aware Quantum Circuit Knitting:** Developed DynaCut, a closed-loop compiler-scheduler that resolves the classical compilation memory wall in Quasiprobability Decomposition (QPD) by treating host RAM ($V_{max}$) as a hard constraint during quantum circuit partitioning and tensor network reconstruction.
2. **Kernighan-Lin (KL) Hypergraph Bisection with Imbalance Tolerance:** Modeled parameterized quantum circuits as weighted hypergraphs and engineered an $O(|V|^2 \log |V|)$ KL bisection engine. By introducing an imbalance tolerance parameter $\epsilon$, the partitioner discovered sparser cut boundaries, reducing cuts from $K \approx 14$ (random) to $K = 8$ on 14-qubit graphs, yielding an astronomical **$5 \times 10^5 \times$ reduction in QPD sampling overhead** ($\Gamma^2 = 9^K$).
3. **Adaptive Tensor Network Knitter with Bounded-Error SVD Truncation:** Replaced naive sum-over-paths accumulation with an adaptive tensor network contraction engine that dynamically toggles between exact dense contraction and Singular Value Decomposition (SVD) truncation when intermediate tensor tree-width threatens classical memory, mathematically proving an amplified truncation error bound $|\Delta \langle H \rangle| \le \Gamma \cdot \epsilon_{SVD}$ via the Schatten 2-norm.
4. **Overcoming the Classical Memory Wall (>99.8% RAM Reduction):** In 26-qubit IBM Heavy-Hex noisy simulations, exact monolithic statevector simulation crashed with Out-Of-Memory (OOM) at $N=26$ (exceeding 1024 MB at $N=24$), whereas DynaCut strictly capped peak classical memory to **$\le 1.74$ MB at $N=26$** under an enforced 256 MB constraint.
5. **Bypassing Noise-Induced Barren Plateaus via Depth Reduction:** In 26-qubit simulations under IBM Heron thermal relaxation ($T_1, T_2$) and depolarizing noise, monolithic circuits mapped to heavy-hex lattices required extensive SWAP routing ($D > 100$), decaying into a noise-induced barren plateau where Zero-Noise Extrapolation (ZNE) failed. DynaCut’s spatial sub-clustering ($N_p \le 7$) eliminated global SWAP cascades, collapsing gate depth to **$D \approx 40$ (71%–75% depth reduction)**, preserving the SNR required for viable ZNE and stable SPSA optimization from cold-start random initialization.
6. **Physical Hardware Validation on 156-Qubit IBM Marrakesh:** Deployed and benchmarked DynaCut on the physical 156-qubit superconducting `ibm_marrakesh` processor from $N=8$ to 50 qubits. Empirically demonstrated that for $K=1$ partitions, physical hardware runtime remained completely flat between **103.7 and 197.4 seconds** (mean 136.5 s) regardless of total qubit count, proving that $O(1)$ cross-boundary entanglement successfully neutralizes the $O(2^N)$ compilation explosion on physical silicon.
7. **Empirical Delineation of the Physical Transposition Frontier:** Validated that while DynaCut successfully transposes the $O(2^N)$ classical memory barrier into an $O(9^K)$ quantum shot-budget constraint, physical execution on `ibm_marrakesh` with $K \ge 2$ triggered QPU execution timeout quotas (Error code 1305; Ran too long). This established a definitive physical boundary: circuit knitting is viable on current NISQ devices strictly for $K \le 2$ or sparse topologies (e.g., $H_2$ molecular potential energy curves with UCCSD ansatz).
8. **Scalable Hamiltonian-Agnostic Physics Benchmarking:** Successfully applied DynaCut to calculate the complete potential energy surface of molecular Hydrogen ($H_2$) across bond lengths 0.5 Å to 2.5 Å using the hardware-mapped UCCSD ansatz, achieving near-exact parity with full configuration interaction eigensolvers.

## 6. Dy-Part: A Dynamic, Noise-Aware Scheduler for Optimizing Hybrid Quantum-Classical Algorithms
* **Paper Title:** Dy-Part: A Dynamic, Noise-Aware Scheduler for Optimizing Hybrid Quantum-Classical Algorithms
* **Authors:** Mufakir Qamar Ansari, Mudabir Qamar Ansari
* **Focus Area:** Quantum Computing, Hybrid NISQ Algorithms, Noise-Aware Scheduling, Variational Quantum Eigensolver (VQE), Combinatorial Optimization
* **Publication Status:** Submitted to *Quantum Machine Intelligence (Springer Nature)*; Code: https://github.com/MufakirAnsari/Dy-Part
### Key Portfolio Highlights (8 Points):
1. **Dynamic Noise-Aware Quantum Scheduling:** Created Dy-Part, an adaptive scheduling framework that resolves the critical bottleneck of static, noise-blind graph partitioning in hybrid quantum algorithms by dynamically determining workload subproblem sizes based on real-time QPU noise calibration ($\epsilon_{gate}$ and $\epsilon_{readout}$).
2. **First-Principles Theoretical Cost Formulation:** Formulated a heuristic cost model balancing two competing physical phenomena: exponential quantum circuit infidelity decay under two-qubit depolarizing gate noise ($C_{quantum} = 1 - (1 - \epsilon_{gate})^{reps \cdot (n_{sub}-1)}$) against superlinear classical recombination penalties ($C_{classical} = \gamma (N_{cuts}/|E|)^\beta$) arising from product-state boundary approximation errors ($\langle Z_u Z_v \rangle \approx \langle Z_u \rangle \langle Z_v \rangle$).
3. **Rigorous Empirical Cost Model Validation ($R^2 = 0.8227$):** Validated the cost model across 1,040 benchmark runs and 2,000 hyperparameter grid searches on noisy simulators, achieving an exceptional determination coefficient of **$R^2 = 0.8227$** with empirical Max-Cut Approximation Ratio (Pearson $r = -0.9071$, Spearman $\rho = -0.8150$, $p < 10^{-12}$), confirming that lower predicted cost directly forecasts superior empirical solution quality.
4. **Sub-4.2 Millisecond Logarithmic Ternary Search:** Exploited the unimodal structure of the composite cost landscape to implement an $O(\log |V| \cdot (|V| + |E|))$ ternary search scheduler with partition caching. In head-to-head empirical ablations across graphs from 6 to 30 nodes, ternary search reduced graph partition evaluations by up to **65.52%** (mean 45.90%) with a $1.77\times$ speedup, executing in strictly under **4.16 ms** (mean 1.74 ms, representing $<0.05\%$ of total execution time).
5. **Architectural Justification of VQE over QAOA:** Formally justified adopting VQE with a hardware-efficient TwoLocal nearest-neighbor ansatz instead of QAOA, which eliminates the exponential $O(4^K)$ classical sampling overhead of circuit-knitted QAOA entangling gates, enabling independent sub-circuits with product-state boundary stitching across decoupled QPUs.
6. **Massive 4,160-Run Supercomputing Benchmark Campaign:** Executed a comprehensive 4,160-run benchmark campaign on the Ohio Supercomputer Center (OSC) Ascend cluster (dual AMD EPYC 7763 64-core processors) evaluating 3-regular graphs ($N=8$ to 20 nodes) across 8 noise levels ($\epsilon_{gate} \in [3.16 \times 10^{-4}, 3.16 \times 10^{-2}]$) and 4 partitioning baselines (Dy-Part, Static $n_{sub}=4$, METIS multilevel, and Random).
7. **Statistically Significant High-Noise Advantages:** Dy-Part achieved the highest overall mean approximation ratio across all 4,160 runs ($0.8489$ vs METIS $0.8448$, Static $0.8434$, Random $0.8398$; ANOVA $F=12.37, p < 10^{-7}$). Paired Wilcoxon signed-rank tests confirmed statistically significant gains in 15 of 40 configurations against Static, 15 of 40 against METIS, and 19 of 40 against Random ($p < 0.05$).
8. **Large Effect Sizes Under Severe Noise Regimes:** Demonstrated that as hardware noise escalates, Dy-Part's dynamic downscaling preserves quantum state fidelity, yielding up to **+4.90% higher approximation ratio on 20-node graphs** ($p = 6.10 \times 10^{-5}$, Cohen’s $d = 1.30$, and up to $d = 1.75$ in extreme noise), confirming dynamic partitioning as an essential software shield against NISQ decoherence.

### Key Portfolio Highlights:
1. **Statewide 10-Year Big Data Safety Analytics:** Led a comprehensive machine learning safety study for ODOT and FHWA analyzing 10 years (2014–2023) of Ohio crash records (24,578 pedestrian and 13,131 bicyclist crashes) to model the determinants of Fatal and Serious Injury (FSI) crashes under ODOT's Vision Zero initiative.
2. **Multi-Source Geospatial Big Data Integration:** Spatially joined ODOT TIMS crash records with statewide roadway inventory data (AADT traffic volume, speed limits, lane counts, lane widths) and OpenStreetMap geospatial layers (generating 50-ft buffer spatial joins for sidewalks, bus stops, and traffic signals) using ArcGIS Pro and GeoPandas.
3. **Cohort-Specific Statistical Problem Formulation:** Partitioned crashes into three distinct behavioral cohorts with markedly different baseline risk profiles: Non-intersection pedestrian crashes (30.1% FSI rate, $n=11,554$), Intersection pedestrian crashes (19.0% FSI rate, $n=13,024$), and Bicyclist crashes (13.3% FSI rate, $n=13,131$).

   - Darkness on unlighted roadways and the absence of sidewalks significantly elevated FSI probabilities, while vehicles proceeding straight through intersections accounted for the majority of intersection FSI crashes.
7. **Production ArcGIS Web Application for Targeted Interventions:** Developed and deployed an interactive ArcGIS Online Web App Builder dashboard featuring dynamic multi-layer GIS mapping and interactive infographics. The tool empowers ODOT traffic safety engineers to query high-risk locations, visualize critical variables, and export prioritized georeferenced CSV lists (e.g., dark unlighted corridors on N Main St, Montgomery County and Harrisburg Pike, Franklin County) for targeted infrastructure investments in street lighting, midblock crosswalks, and road diets.

## 8. High-Sensitivity Detection of Invasive Ductal Carcinoma via Domain-Specific SimCLR Pre-Training

* **Focus Area:** Medical Computer Vision, Self-Supervised Learning (SSL), Computational Pathology, Digital Oncology, ResNet50

2. **Leak-Free Patient-Stratified Validation Protocol:** Enforced a strict patient-stratified split (90% train / 146 patients, 5% validation / 8 patients, 5% test / 8 patients / 13,876 patches), ensuring that patches from the same patient never crossed split boundaries, eliminating clinical data leakage common in patch-level pathology literature.

7. **Inherent Robustness to Inter-Laboratory Staining Variability:** Deliberately omitted stain normalization algorithms (Macenko/Vahadane) during pre-training, proving that SimCLR's composition of stochastic color jitter, rotation, and Gaussian blur augmentations intrinsically learns stain-invariant representations across diverse laboratory scanning environments.

## 9. Racing to Idle: Energy Efficiency of Matrix Multiplication on Heterogeneous CPU and GPU Architectures
* **Paper Title:** Racing to Idle: Energy Efficiency of Matrix Multiplication on Heterogeneous CPU and GPU Architectures
* **Authors:** Mufakir Qamar Ansari, Mudabir Qamar Ansari
* **Focus Area:** Green Computing, Energy-Efficient HPC, Heterogeneous Architecture Benchmarking, Performance-per-Watt
* **Publication / Identifier:** Research Square (DOI: 10.21203/rs.3.rs-7890483/v1), October 2025

### Key Portfolio Highlights:
1. **Heterogeneous High-Performance Energy Profiling:** Executed a comprehensive empirical benchmark comparing execution time, energy-to-solution, and power efficiency for single-precision matrix multiplication ($4096 \times 4096$ to $8192 \times 8192$) across three compute architectures within a single heterogeneous platform: multi-core CPU (AMD Ryzen 7 5800H), integrated GPU (AMD Radeon Vega iGPU), and discrete GPU (NVIDIA GeForce GTX 1650 Mobile).
2. **Empirical Validation of the "Race-to-Idle" Principle:** Provided direct quantitative evidence that minimizing total energy consumption depends on rapid workload execution and swift return to idle states rather than low instantaneous power draw. While the discrete GPU drew higher peak power (~46–60 W), it finished the $4096 \times 4096$ workload in **0.35 seconds** and consumed only **11.7 Joules**, compared to the CPU which drew 53.5 W over 29.2 seconds and consumed **1,562.5 Joules**.
3. **93.5× Speedup and >50× Greater Energy Efficiency:** The discrete GPU demonstrated a massive **93.5× speedup** over the multi-core CPU for large matrices, while consuming **just ~1% to 2% of the CPU's total electrical energy** (reducing energy per GFLOP from 332.0 J/GFLOP down to **0.03 J/GFLOP**).
4. **131× Boost in Performance-per-Watt:** The dGPU attained a peak throughput of **391.8 GFLOPS** at **11.8 GFLOPS/Watt**, compared to the CPU's 4.7 GFLOPS at 0.09 GFLOPS/Watt, demonstrating an astounding **$131\times$ improvement in computational efficiency per watt**.
5. **Orders-of-Magnitude Energy-Delay Product (EDP) Superiority:** Evaluated composite performance-energy trade-offs via Energy Delay Product (EDP), showing that the discrete GPU consistently maintained an EDP below **1,000 J·s**, outperforming the integrated GPU by **$10\times$** and vastly outstripping the CPU (which reached into the millions of J·s).
6. **Characterizing the Integrated GPU (iGPU) Efficiency Envelope:** Benchmarked the AMD Radeon Vega iGPU via OpenCL, showing it delivered **47.0 GFLOPS at 16.8 W average power (2.8 GFLOPS/Watt)** and consumed 49.0 Joules. Identified the iGPU as an optimal, highly energy-efficient architecture for power-capped, battery-dependent mobile or edge systems where thermal envelopes forbid high-power discrete bursts.
7. **Hardware-Counter Power Measurement Methodology:** Developed a non-intrusive, production-grade profiling methodology using Linux `perf` to access Intel/AMD RAPL hardware counters (`power/energy-pkg/`) for the CPU/iGPU shared silicon package, synchronized with 10 Hz NVML polling via `nvidia-smi` for the discrete GPU.
8. **Roofline Modeling and Memory Subsystem Bottlenecks:** Analyzed sustained memory bandwidth and operational intensity across devices, revealing that dGPU achieved $>2.5$ GB/s bandwidth and operated close to theoretical compute rooflines, whereas CPU performance was severely throttled by memory bus latency ($<0.05$ GB/s) and serial architectural constraints.

## 10. Accelerating Matrix Multiplication: A Performance Comparison Between Multi-Core CPU and GPU
* **Paper Title:** Accelerating Matrix Multiplication: A Performance Comparison Between Multi-Core CPU and GPU
* **Authors:** Mufakir Qamar Ansari, Mudabir Qamar Ansari
* **Focus Area:** High-Performance Computing (HPC), GPU Kernel Optimization, OpenMP & CUDA C++ Parallelization
* **Publication / Identifier:** arXiv:2507.19723v1 [cs.DC], July 2025

### Key Portfolio Highlights:
1. **Heterogeneous HPC Benchmark Architecture:** Engineered and benchmarked three distinct, highly optimized implementations of dense single-precision matrix-matrix multiplication ($C = A \times B$) in C++: a naive sequential baseline, a multi-threaded CPU kernel using OpenMP with `#pragma omp parallel for collapse(2)`, and a massively parallel discrete GPU kernel written in CUDA C++ utilizing shared-memory tiling.
2. **593× Empirical Speedup over Sequential Baseline:** Evaluated scaling across square matrices from $128 \times 128$ to $4096 \times 4096$ on a consumer heterogeneous platform (AMD Ryzen 7 5800H 8-core/16-thread CPU and NVIDIA GeForce GTX 1650 Mobile GPU). For a $4096 \times 4096$ matrix, the CUDA kernel completed execution in **663.24 ms** versus **393,280.52 ms (~393.3 s)** for sequential execution, achieving an empirical speedup of **592.97×**.
3. **45.7× Speedup over Optimized Parallel CPU:** Against the 16-thread OpenMP parallel CPU implementation (which achieved 30,332.07 ms, a 12.97× speedup over sequential), the CUDA GPU kernel delivered a direct **45.73× acceleration**, proving that many-core GPU architectures achieve order-of-magnitude computational throughput gains over fully saturated modern multi-core CPUs for dense linear algebra.
4. **End-to-End Latency & Transfer Accounting:** Implemented comprehensive wall-clock timing using `std::chrono::high_resolution_clock`, strictly capturing host-to-device memory allocation, PCIe input data transfer (`cudaMemcpyHostToDevice`), kernel execution, and device-to-host result transfer (`cudaMemcpyDeviceToHost`), ensuring production-realistic performance accounting.
5. **Characterization of Three Architectural Scaling Regimes:** Discovered and mathematically characterized three distinct operational regimes: (i) *Parallel Overhead Dominance* at small problem sizes ($128 \times 128$, where OpenMP thread creation/synchronization overhead caused a 7.10 ms vs. 2.18 ms slowdown), (ii) *Predictable CPU Scaling* plateauing at 12–14× speedup from $256 \times 256$ upwards across 16 threads, and (iii) *Superlinear GPU Scaling* accelerating from 8.29× at $128 \times 128$ to 593× at $4096 \times 4096$.
6. **Empirical Validation of the Classic "100× GPU vs. CPU" Myth:** Provided contemporary empirical validation of Lee et al.'s seminal ISCA study on realistic speedup bounds, demonstrating that when comparing against an optimized, vector-parallel multi-core CPU baseline, the GPU advantage on modern commodity hardware is a realistic, non-mythological **~45× advantage**.
